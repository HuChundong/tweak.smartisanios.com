# tweak.smartisanios.com

LightBoard（iOS 图标主题与全天动态阴影引擎）的产品宣传页，发布于 <https://tweak.smartisanios.com>。

Promo site for LightBoard, an icon theme and all-day shadow engine for jailbroken iOS. This repository holds only the static site and its media, not the product source code.

本仓库只包含静态宣传页面及其展示素材，不包含 LightBoard 产品源码。页面中的影片与图片版权保留，未经许可请勿转载或再分发。
